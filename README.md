# Habit-Tracker

A command line written using Python that allows users to set and track their daily and long-term habits

# Features
- Set multiple habits
- Mark down how often they are doing a specific habiy
- See a review of how many times a user did a certain habit/if they did it at all that day
- Uses only Python

# Installation
- Python3 required
- https://www.python.org/downloads/

# How to use
- Run from terminal
